# 🐍 Snake Water Gun Game

A simple and interactive **Snake Water Gun Game** built using **Python** and **Tkinter GUI**. The player competes against the computer, which randomly selects Snake, Water, or Gun. The game instantly displays the winner based on predefined rules.

## ✨ Features

- 🖥️ Simple Tkinter GUI
- 🎮 Interactive gameplay
- 🎲 Random computer choice
- 🏆 Instant result display
- 🔄 Easy to play
- 🐍 Beginner-friendly Python project

## 📌 Game Rules

- Snake 🐍 drinks Water 💧 → Snake Wins
- Water 💧 drowns Gun 🔫 → Water Wins
- Gun 🔫 kills Snake 🐍 → Gun Wins
- Same choice → Draw

## 🛠️ Technologies Used

- Python
- Tkinter
- Random Module
